# Feature Engineering with ColumnTransformer

This project focuses on feature engineering using scikit-learn's
ColumnTransformer on a COVID dataset.

## Objective
To apply different preprocessing techniques to different columns
in a clean and scalable way.

## Techniques Used
- SimpleImputer for handling missing values
- OneHotEncoder for nominal categorical features
- OrdinalEncoder for ordered categorical features
- ColumnTransformer to combine all transformations

## Dataset
The dataset contains patient-related information such as:
- Fever
- Gender
- City
- Cough
- COVID status (target variable)

## Technologies
- Python
- Pandas
- Scikit-learn
